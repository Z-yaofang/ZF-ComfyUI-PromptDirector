# ZV 固定出口槽位

> 兼容状态：固定槽位不再是新工作流的默认交互。现有槽位节点、工程映射和执行契约全部保留，素材台只在旧工程确实含有槽位时显示折叠的“旧版固定槽位（仅兼容）”面板。

旧工程可以继续通过固定 `slot_id` 解析素材；已有出口节点 ID、端口和下游连线保持。新素材出口请在轨道上选中素材，使用“发送图片N / 发送视频N / 发送音频N”创建直接出口，再用 `ZFI` 管理需要长期保持的下游分线。

同类型有多个槽位时，必须在下拉框明确选择目标，每项显示“槽位名 · 当前文件名/未指定”。界面可保留用户此前明确选择的目标，不按画布位置、轨道顺序或第一个空槽猜测。主按钮始终显示实际目标。检查器操作区固定在顶部，素材池尚未入轨的条目不显示发送动作。

“旧版固定槽位”默认折叠；展开后可查看或清空旧映射。列表高度最多 150px，增加到 20 个槽位也不会扩展素材台尺寸或两个工程端口。界面不再新增、重绑或选择目标槽位。

删除/卸载素材会清空引用它的映射；槽位定义、序号、节点和连线保留。发送、清空、删除均可撤销/重做，并随工作流保存。素材台撤销“另建出口”时保留已创建的接口和可能已接好的模型连线，只清空该次赋值；重做恢复赋值。图级历史由 ComfyUI 管理，不把素材台的局部历史当作图节点删除操作。

## 数据契约

`zv-media-project-v2` 新增可选字段，缺少该字段的旧项目继续保持原模式。新工程默认空列表；旧项目可在面板内显式启用槽位，不会改写旧出口。

```json
{
  "outlet_slots": {
    "version": 1,
    "items": [
      {"slot_id": "v1-video-1", "kind": "video", "ordinal": 1, "binding_id": null}
    ]
  }
}
```

严格禁止未知字段、重复 `slot_id` 和重复的同类型序号。最多 256 项；`kind` 仅允许 `picture/video/audio`，序号为 1–1000000 的整数。`slot_id` 与非空 `binding_id` 仅允许 1–96 位英文字母、数字、下划线或短横线。空映射必须为 `null`，不能是空字符串。显示名由类型和持久序号生成；图片用稳定 `item_id`，视频/音频用稳定 `clip_id`。重排轨道或槽位列表不会改变身份。

| 技术 ID | 必填输入 | 固定输出顺序 |
| --- | --- | --- |
| `ZVPictureSlotOutlet` | `media_project: ZV_MEDIA_PROJECT`、`slot_id: STRING` | `image: IMAGE`、`manifest_json: STRING`、`report: STRING` |
| `ZVVideoSlotOutlet` | 同上 | `frames: IMAGE`、`original_audio: AUDIO`、`manifest_json: STRING`、`report: STRING` |
| `ZVAudioSlotOutlet` | 同上 | `audio: AUDIO`、`manifest_json: STRING`、`report: STRING` |

三类节点的类名与注册键一致，分类为 `ZV/视频创作/素材取证`。执行依次从输入工程解析槽位、查找稳定素材 ID，然后复用原标准媒体输出路径。图片全尺寸、视频处理窗口交集和帧率、44100Hz 双声道音频、PTS 采样、合法来源校验与原限制均不改变。视频原声仍来自同一视频的合法关联原声；停用或不存在时为 `None`。manifest 增加 `outlet_slot`，报告增加槽位名。旧三类直接 ID 出口及时间线混音出口完全保留。

空槽、槽位不存在/类型不符、被引用素材已不存在，均以可操作的中文错误终止，不查找下一个素材。仍关联视频的原声不能作为独立音频槽位输出。标题显示“ZV 视频槽1 · 文件名/未指定”；青色表示已赋值，棕黄色表示空槽，红色表示无法解析。widget 中 `slot_id` 是出口身份，property 只是保存的描述信息。

## 本地操作与云端执行边界

发送/清空只更新本地 `project_data` JSON 的槽位映射、标题及颜色，并标记画布需要保存。不会调用 `queuePrompt` / `api.queuePrompt`，不会调用 normalize、素材扫描、媒体解码接口，不使用轮询。更新标题只顺着当前素材台输出 0 的现有边找直接出口，不反向扫描模型输入或遍历下游网络。

工程普通编辑/导入与预览仍沿用现有本地接口；模型解码只在用户正常执行、且输出被消费时发生。执行只读取传入的工程及槽位 ID，不依赖前端图或当前画布。云端需安装本插件的新类和可访问的合法素材；槽位映射不会上传或搬运源文件。本轮仅验证本地隔离环境，未运行云端或模型生成。
