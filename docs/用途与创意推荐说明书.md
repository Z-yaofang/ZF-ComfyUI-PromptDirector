# ZF 提示词创意导演：用途与创意推荐说明书

这份说明书帮助第一次使用导演台的人快速完成“用途 + 视觉方法”的选择。

## 先记住一句话

- **用途**回答“这张图最后拿来做什么”。
- **视觉方法**回答“观众第一眼会以什么方式看到它”。
- **世界观或取材主题**提供画面里可以使用的人物、环境、物件和规则。
- **用户提示词**是本次必须优先完成的具体内容。

例如，同一句“女孩在雨中等车”：

- 用途选择“纪实与生活场景”，视觉方法选择“决定性瞬间”，会成为可信的生活摄影。
- 用途选择“电影海报与活动主视觉”，视觉方法选择“符号化主视觉”，会成为传播型海报画面。
- 用途选择“故事分镜图”，视觉方法选择“漫画页与动作转场”，会成为一张包含连续事件的复合分镜图。

## 30 秒选择法

1. 先在左侧用途列表中找到最终交付物；不要先从喜欢的画风倒推用途。
2. 保持“推荐搭配”开启，导演台会把更适合当前用途的视觉方法放在前面，并自动选择第一项。
3. 第一次使用时直接采用自动选择的第一项；只有明确知道想改变观看方式时再换视觉方法。
4. 一次通常只启用一个组合。需要补充表达时再增加第二个组合，并让第一组承担主要任务、第二组只补充一种能力。
5. 同一任务避免同时堆叠多个相互竞争的版式、媒介或镜头概念。

## 视觉方法应该怎样理解

| 视觉方法分类 | 主要解决的问题 | 适合的第一反应 |
| --- | --- | --- |
| 直接呈现 | 主体怎样被清楚看见 | 不确定怎么选时，先选“直接表现” |
| 事件与关系 | 人物、动作和瞬间怎样成立 | 纪实、人像互动、运动和食品飞溅 |
| 空间叙事 | 环境怎样成为画面主角 | 建筑、旅行、世界观和沉浸空间 |
| 符号与合成 | 怎样形成强记忆和传播主形 | 海报、封面、品牌、音乐和活动主视觉 |
| 信息与版式 | 怎样展示多项内容和阅读顺序 | 报告、教程、产品说明、角色表和系列排版 |
| 材质与媒介 | 画面通过什么物理质感被观看 | 纸雕、拼贴、丝网印、复古媒介和材料展示 |
| 尺度与模型 | 怎样通过比例变化制造新奇 | 微缩、巨物、沙盘和系统世界 |
| 连续叙事 | 怎样在一张复合图里交代事件前后 | 故事分镜和漫画动作转场 |

## 四种必须单独理解的情况

### 1. 故事分镜图

- 必须把“故事分镜图”选为用途，只选择“分屏、几何分格与多焦点版式”并不会自动获得连续剧情。
- 首选“漫画页与动作转场”。
- `count` 表示一张复合图中的有效分镜数量，不是生成图片的批次数。
- 成图工作流的 latent batch 保持为 `1`。
- 相邻格会承担事件建立、接触、结果和反应，空余版面不会用纯黑假格补齐。

### 2. 角色资产与多视角设定

- 首选“百科图鉴与标准视图”。
- 想在一张图里得到完整正侧背设定时，`count` 使用 `1`。
- 用户提示尽量写稳定角色锚点，例如年龄阶段、脸型、发型、身体比例、服装、配色和代表道具。
- 标准视图强调同一角色、同一比例、同一站立基线和低透视畸变，不适合同时要求夸张动作大片。

### 3. 产品和电商图

- “产品商业摄影”负责一张产品照片本身；“社媒系列与电商传播”负责标题、卖点、版式和发布职责。
- 商品主图优先“产品英雄与纯净背景”。
- 结构与配件较多时选择“俯拍平铺与样品板”或“百科图鉴与标准视图”。
- 每张图只承担纯净主图、结构展示、材质细节、功能演示或使用情境中的一个主要职责。

### 4. 世界观场景

- 世界观决定画面中存在什么；“世界观概念艺术与场景原画”用途决定把它制作成可继续开发的场景设计。
- 想突出生活环境和空间纵深，选择“环境叙事”。
- 想解释完整空间系统，选择“等距沙盘与系统模型”或“剖面透视与内部世界”。
- 只需要普通人物照片时，不要因为接入了世界观就自动选择概念艺术用途。

## 添加第二组组合的原则

第二组不是第二张图，也不是让两种风格平分画面，而是给第一组增加一种明确能力。

合适的补充示例：

- 产品商业摄影 + 产品英雄与纯净背景，再补充“材质主导”，用于强化表面工艺。
- 电影海报与活动主视觉 + 符号化主视觉，再补充“叙事合成”，用于增加背景事件层。
- 世界观概念艺术与场景原画 + 环境叙事，再补充“尺度置换”，用于强化巨构尺度。

不建议的做法：

- 同时启用多个完全不同的主版式。
- 同时要求写实摄影、纸雕、丝网印、微缩模型和漫画页面。
- 为了“更丰富”添加三组以上没有职责区别的组合。

## 常见选错原因

- **把用途当画风：**“电影海报”不是固定电影感滤镜，它首先是传播任务。
- **把视觉方法当内容：**选择“微缩模型”不会自动规定人物、地点和故事，这些内容来自用户提示与世界观。
- **把图片数量当宫格数：**普通用途的 `count=5` 会产生五条独立提示词；只有“故事分镜图”会把数量解释为一张图中的分镜数。
- **误选测试模式：**正常成图使用“创意迁移”；“参考图创意提取测试”用于隔离排查，不会保留普通用途组合。
- **组合越多越好：**多个强视觉概念会争夺画面，结果通常比一个清楚组合更差。
- **提示词写得太满：**用户只需写必须发生的事情，导演台负责补充专业结构；需要严格保留的数量、身份、动作和文字应明确写出。

## 最稳妥的默认选择

如果仍然不知道怎样选：

1. 人物任务选择“人物与场景摄影 + 直接表现”。
2. 场景任务选择“世界观概念艺术与场景原画 + 环境叙事”。
3. 商品任务选择“产品商业摄影 + 产品英雄与纯净背景”。
4. 海报任务选择“电影海报与活动主视觉 + 符号化主视觉”。
5. 信息任务选择“信息报告与视觉分析 + 编辑网格”。
6. 连续剧情选择“故事分镜图 + 漫画页与动作转场”。

先得到一张语义清楚的图，再根据结果只更换视觉方法进行比较，是学习导演台最快的方式。

## 导演台附带的流程工具

### ZF文本动态多路点选

- 路线数量可以设置为 1–32，节点只显示相应数量的文本输入。
- 按钮选择哪一路，队列执行时只请求这一条懒执行路线，不会启动其他反推或写作分支。
- 点击“空文本”会明确输出空字符串和路线编号 `0`，适合表示“本次不使用世界观或反推文本”。
- 它不检查哪一路有内容，也不会自动回退；这让一次按钮选择对应一次确定执行路径。

### ZF任意过滤器

- “判断逻辑”决定什么时候处理，“输出内容”决定命中后产生什么结果。
- “无输出（None，跳过此路）”会让后面的任意切换继续寻找下一路。
- “空文本（截断后路）”表示这一路已输出空字符串，后面的任意切换应停在这里。
- “删除指定内容后输出”按每行一个普通文字、短语或符号处理，不使用正则表达式。
- 未命中判断时，输入原样通过；`0` 和 `False` 不会被当成空值。

这两个节点与 `ZF-ComfyUI-Helper` 中的原节点使用不同内部类名，因此帮助插件可以继续保留，旧工作流也不会被替换。
