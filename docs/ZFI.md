# ZFI 多路转接排

`ZFI` 是 1–32 路彼此独立的纯前端虚拟转接节点。每一路与 ComfyUI 官方转接点的执行语义相同：提交工作流时，`output_N` 会直接解析到 `input_N` 的真实上游，`ZFI` 本身不会进入后端提示词、不会执行，也不会保存素材或运行结果缓存。普通 ComfyUI 输出可连接任意数量的下游，因此右侧模型连线只需接一次，换素材时重接左侧对应的一根线即可。

- `channel_count`：可见通道数，默认 3；减少数量会移除超出范围的端口及其连线。
- `channel_notes`：界面显示为“通道名称”。只填一个基础名称时会为全部通道自动编号，例如 3 路填写“图片”会显示“图片1 / 图片2 / 图片3”；也可使用 `|`、中英文逗号、分号或换行逐路指定名称。空白通道显示序号。
- 输入和输出类型均为通配类型，可转接图片、帧批次、音频、文本、数值及其他 ComfyUI 数据。
- 工作流只保存通道数量、备注、端口和现有分线；不保存任何经过转接的数据。
