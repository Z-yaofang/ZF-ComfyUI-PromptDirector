| 内容 | 更新后的用法 |
| --- | --- |
| 长曝光与运动轨迹 | 固定机位或跟拍中选一种，让静止锚点和连续轨迹共同表达时间；限制无来源光轨、重复肢体和全画面模糊。 |
| 镜面反射与折射 | 明确实体、相机、镜面或透明介质的关系，以倒影、折射或焦散组织画面，保留主体识别。 |
| 错视与透视机关 | 将机关集中到一个观察位或局部空间连接，维持其余结构和光照连贯。 |
| 分屏与几何分格 | 增加按需启用的跨框道具互动，保持格数、节拍和关键内容可读。 |
| 尺度置换 | 外部巨构题材通过外轮廓、窗阵、支撑、投影和大气纵深说明规模；不默认添加人物或动物。 |
| 世界观概念艺术 | 用户选择巨构、砼核方向时补充外部体量和受力结构；保留用户指定的室内或局部视点。 |
| 日历、年鉴与系列收藏 | 同一人物或产品跨期出现时固定核心识别特征、色系和材质，明确哪些内容可以变化。 |
| 剖面透视与内部世界 | 多层居住或功能舱明确适合用途的出入口与层间通行方式；家具、隔断与设备服从外壳容积。 |
| 撕纸拼贴与 Zine | 按需增加破纸出框，明确开口、撕边、穿出方向与前后遮挡。 |
| 微缩模型 | 日常物承载微缩世界时，将其开口、折痕或材料转为入口、楼层、外墙或地形。 |
| 符号化主视觉 | 按需替换器物的通常输出物，保留起点、方向、路径和落点，以功能关系表达隐喻。 |
| 层叠纸雕与立体剪纸 | 纸雕灯与背光纸艺明确光源、透光、镂空及层间投影关系。 |
| 直接表现 | 场景已有合适前景时采用自然框景，完整保留主体识别和关键动作。 |
| 环境叙事 | 遗迹、废弃场景的锈蚀、剥落与沉积应符合材料、重力和暴露位置。 |
