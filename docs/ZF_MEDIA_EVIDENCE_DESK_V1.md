# ZV 通用素材取证台

入口为 `ZVUniversalMediaEvidenceDesk`，显示名 **ZV 通用素材取证台**。它负责导入、预览、剪辑和保存素材工程，不观察内容、不填写采访要求，也不调用生成模型。下游入口见[节点指南](NODE_GUIDE.md)。

## 常用操作

1. 点击“导入素材”或把图片、视频、音频拖入素材池。点击池中素材可预览；拖入对应轨道后才形成剪辑项。
2. 图片按从左到右排序，没有视频时长。视频和音频共用秒时间轴；拖动片段移动，拖动两侧把手裁剪。右侧检查器可输入轨道起点、源入点、源出点。
3. 先定位黄色播放头，再点击要切的视频或音频，最后点“分割”。选择片段不会移动黄线；黄线须处于所选片段内部，选错片段会提示。图片卡片不按时间分割。
4. 含原声的视频默认带绑定音频。绑定状态下，移动、裁剪、分割同时作用于视频和原声；要独立编辑音频，先“解绑音频”。
5. 删除轨道项只移除该剪辑引用；素材池“×”卸载该资产及其轨道引用。二者不删除磁盘原文件，可在当前编辑会话撤销。
6. 保存 ComfyUI 工作流会保存工程及视图状态，包括播放头、选择、缩放、滚动和吸附。撤销历史仅限当前会话，不保存到工作流。

### 黄色播放头与精确帧定位

播放头秒数右侧的“工程帧”框从 **0** 开始，按 `project_clock.fps` 定位：

- 输入整数帧号，按 Enter 或点“定位”；黄线和时间线预览跳到 `帧号 / 工程 fps`。输入尚未确认时不跳转。
- 数字定位不受吸附影响；手动改变播放头时，输入框同步显示当前工程帧号。
- 点击时间尺，或拖动黄线顶部三角，可以改变位置。点视频、音频或轨道空白不移动黄线。
- 先定位后选中片段再分割，不需要点击片段后重复找回原位置。

工程帧不是原视频帧号。预览下方的“源帧 / 估算帧”按源帧率计算，显示从 1 开始；源帧率与工程 fps 不同时，两处数字不同是正常现象。

### 预览与截图

点击素材池预览完整素材；定位或播放时间线时，按剪辑位置显示当前视频并同步已启用音频，空白处保留黑场与静音间隔。视频播放使用最长边 480 像素的静音代理，保留原片每帧及其相对时间戳，原声音频单独同步。暂停定位时改从登记的原视频解码并显示实取画面和 PTS；逐帧判断切点以暂停画面为准。代理和取帧都不改写原文件。

只有完整帧数探测且帧率稳定时显示“源帧”；VFR 或稳定性尚未确认时显示“估算帧”。播放中的帧号按工程时钟估算，可能与浏览器正在显示的帧短暂相差；暂停后以原片实取 PTS 和画面确认。剪辑依据原素材秒数保存，不以预览代理重算源帧率。

“截图”从黄线所在视频的原文件解码单帧，保留原像素尺寸和方向，只加入素材池，不自动加入图片轨、不设置首尾帧。截图期间冻结请求时的来源和时间；空白区或无视频时不可截图。截图卡标为 `image`，普通图片标为 `picture`；内部同属图片，可照常入轨和发送。

## 三个输出及画布输入

| 输出顺序 | 名称 / 类型 | 用途 |
| --- | --- | --- |
| 0 | `media_project: ZV_MEDIA_PROJECT` | 正规化的素材工程，供剪辑出口、H3 和分段台消费 |
| 1 | `project_json: STRING` | 同一工程的 JSON 文本 |
| 2 | 原素材来源 · `ZV_ORIGINAL_SOURCES` | 完整素材池来源，接原素材出口的 `original_sources` 输入 |

素材台自身输出的是计划与来源，不是图片帧批次。可选 `width` / `height` 须成对连接，写入 `output_canvas`；读取视频的下游出口在解码时适配画布，不改写原文件。只有实际执行相关出口时才读取对应媒体。

需要已剪片段，使用[稳定 ID 出口](ZV_MEDIA_OUTLETS.md)；需要完整原文件，使用[原素材出口](H3_V2_07_SOURCE_BINDING.md)；H3 使用采访表的 `reference_plan` 接固定素材出口，不能把三种范围混用。

## 处理窗口与三个时钟

新建工程采用**通用预设**，不限制为 H3，不强制 24 fps 或 15 秒。工程显示 fps 默认 24，处理窗口参考 fps 默认 24；默认值不等于模型限制。

| 时钟 | 作用 |
| --- | --- |
| `project_clock.fps` | 工程帧输入和工程帧读数 |
| 素材 `probe.fps` 与真实 PTS | 原视频的帧读数及解码时间 |
| `processing_window.fps` | 当前处理窗口参考帧率，供相关出口采样 |

处理窗口是时间尺上的青色范围，可拖动或在下方输入起止秒和参考 fps。窗口不等于视频切点；移动窗口不会重新裁剪轨道片段。只有选用的预设要求对齐时，窗口拖动才按其目标帧网格量化。

H3 单段预设要求 24 fps、48–360 帧、最多 15 秒；H3 长参考预设针对每段约束，总范围可以更长。切换预设不移动已有窗口或素材切点。通用、用户预设和具体执行层限制见[处理预设](ZV_PROCESSING_PRESETS_V2.md)。

## 工程契约

当前定义为 [zv-media-project-v2.schema.json](../schemas/zv-media-project-v2.schema.json)，`schema_version: 2`。读取旧工程时保留有效素材和剪辑数据，不因此重新注册旧节点。

| 字段 | 责任 |
| --- | --- |
| `assets` | 稳定资产 ID、安全来源句柄、探测事实；截图附服务器确认的来源信息 |
| `picture_track` | 图片项 ID、资产 ID、顺序 |
| `video_track` | 视频片段 ID、资产 ID、轨道起点、源入出秒数、原声绑定 |
| `audio_track` | 音频片段及启停、绑定关系 |
| `processing_window` / `processing_preset` | 窗口范围、参考 fps 与当前规则快照 |
| `output_canvas` | 可选的下游视频解码画布 |
| `label_map` | 后端重新生成的 Picture / Video / Audio 连续编号 |
| `validation` / `preset_compatibility` | 工程合法性与预设兼容性，分别计算 |

时间区间是半开区间 `[in, out)`，秒数为保存依据；帧显示使用 `floor(seconds × fps + 0.5)`。标签、帧数等派生结果每次重新计算，不相信旧工作流中缓存的值。重排不改变稳定 ID，分割右半段创建新 ID；原声保持与相应视频段的关系。

工程错误显示红色；工程有效但不满足所选预设时显示橙色；有效且兼容显示绿色。错误不靠静默移动切点、截短范围或更换素材来掩盖。

## 存储与边界

导入原件与缓存存于 ComfyUI 的 `input/zf_media_evidence/`，其中 `originals/` 保存导入文件，`cache/` 保存登记和代理数据。工程引用受控的来源句柄，不接受任意文件路径或 URL。执行时重新核验来源；缺失或改变须重新导入或复测。

支持静态 PNG、JPEG、WebP、BMP，视频 MP4、MOV、MKV、WebM、AVI，以及 WAV、MP3、M4A、FLAC、OGG 音频；以实际解码类型为准。当前单文件上限 512 MiB，原素材总量 8 GiB，单个源音视频最长 3600 秒；工程最多 128 个资产、每轨 512 项、12 小时时间轴，JSON 最多 2 MiB。媒体处理还有解码尺寸与超时限制，失败会报告原因。

预览和波形依赖已有 FFmpeg、Pillow、PyAV、NumPy 等运行环境，不自动下载工具或模型。素材删除操作不清理磁盘原件或缓存，也不上传素材到互联网。

## 回归入口

在具备插件依赖的 Python 环境、插件根目录执行：

```text
python -m pytest -q --rootdir=tests --confcutdir=tests --import-mode=importlib tests/test_media_evidence.py
python tests/media_evidence_smoke.py
node --test tests/media_evidence_core.test.mjs
```

浏览器检查使用 `tests/media_evidence_ui_smoke.mjs`、`tests/media_evidence_monitor_smoke.mjs` 和 `tests/media_evidence_monitor_media_smoke.mjs`，参数见脚本开头。程序检查不替代实际 ComfyUI 画布、稀有编解码器及云端环境复测。
